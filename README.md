# Finanzas personales

App web local para registrar ingresos y gastos, consultar balances mensuales y ver gastos por categoría.

## Abrir en VS Code
1. Descomprime esta carpeta.
2. En VS Code, selecciona **Archivo → Abrir carpeta** y elige `finanzas_personales_vscode`.
3. Abre `index.html` en el navegador. Puedes usar la extensión **Live Server** para recarga automática.

## Estructura
- `index.html`: estructura y formulario de la interfaz.
- `css/styles.css`: estilos y diseño responsive.
- `js/app.js`: lógica, cálculos y almacenamiento local.
- `README.md`: estas instrucciones.

## Datos
Los movimientos se guardan en `localStorage` del navegador. No se envían a ningún servidor.
